Clinical intake

Describe the problem

Include these details when possible:
  1. General body area, for example arm, leg, hand, or foot.
  2. Specific location, for example wrist, ankle, elbow, knee, or shoulder.
  3. How it happened, for example fall, twist, impact, sport, or traffic injury.
  4. When it happened and whether symptoms changed over time.
  5. Main symptoms, for example pain, swelling, bruising, or reduced movement.
  6. Current function, for example grip, walk, bear weight, or move the joint.
  7. Numbness, tingling, color change, coldness, or reduced sensation, even if absent.
  8. Visible deformity, abnormal alignment, bleeding, cut, or open wound, even if absent.

This mode only handles health-related musculoskeletal injury or symptom descriptions.
