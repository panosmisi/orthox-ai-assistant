# Stage 3

This folder contains the report-generation and reasoning layer of OrthoX.

It includes:

- construction of the unified analysis payload,
- RAG evidence handling,
- source relevance checks,
- clinical-context and patient-note generation,
- safety guardrails,
- explainability text,
- final display and report rendering logic.

The modules are kept as source code only. Generated experiment outputs, local caches, and large result folders are intentionally excluded from the GitHub-ready package.
